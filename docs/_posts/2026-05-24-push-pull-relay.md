Cross-modal compensation in the relay is asymmetric.

L17 ablation → relational CV **decreases** (3.7% → 2.1%). Compensation: losing generic sorting causes relational representations to converge across names.

L16 ablation → generic CV **increases** (3.5% → 5.1%). No compensation: losing relational sorting causes generic representations to diverge further.

The relationship is directed:

**L16 → L17: cooperative.** Relational sorting supports generic sorting. When L16 sorts names relationally, this helps L17 organize the generic channel. Remove L16 and generic CV rises (L17 loses useful input).

**L17 → L16: competitive.** Generic sorting suppresses relational differentiation. When L17 sorts names generically, this actively pushes relational representations to converge. Remove L17 and relational representations become more similar across names.

L16 differentiates. L17 constrains. Together they find the operating point: different enough for identity, similar enough for shared format.

This is why identity-as-format works. L17's suppressive role prevents the system from treating identity as pure content differentiation (maximum name separation). Instead, it maintains format-level coherence — a shared geometric structure that all names occupy, with name-specific modulations on top. L16 creates the modulations. L17 enforces the shared structure.

Remove L17 and you get identity-as-content: names maximally separated, no shared format, higher PR ratio but less structured. Temporarily "stronger" identity that's actually less organized.

The relay isn't a pipeline flowing left to right. It's a push-pull system where L16 and L17 compete to set the balance between differentiation and coherence. The operating point IS the identity format.
