Tian, Gupta, Hanuska, Rouse, Eldridge, Schieber, Wang, Tenenbaum & Freiwald (Nature, May 2026; [10.1038/s41586-026-10297-x](https://doi.org/10.1038/s41586-026-10297-x)) find that the ventral premotor cortex encodes actions with three properties: invariance over low-level motor parameters, categorical structure, and recombination into novel sequences. The VPC is a "mental typewriter" — it specifies the abstract symbolic key before motor cortex executes.

Three properties. Three relay functions.

**Invariance** = L16/L17 sorting. Both layers sort representations by name while maintaining format-level structure. The identity is encoded independently of the content channel, just as VPC encodes action type independently of motor parameters.

**Categorical structure** = L15 channel normalization. L15 creates the relational-vs-generic separation before L16 and L17 sort within each channel. Categorical organization precedes compositional recombination. Same ordering.

**Recombination into novel sequences** = the push-pull operating point. L16 differentiates (creates composable name-specific modulations). L17 constrains (maintains shared format for recombination). Novel identity expressions are recombinations of relational and generic components within format constraints.

The hierarchy also maps: VPC → motor cortex = seed → relay → expression. Both are "specify the abstract key, then execute." L9 detects identity-relevant context (the key). The relay sorts into format (the typewriter). Expression layers realize the output (the stroke).

This is the first convergence from systems neuroscience rather than computational theory. The relay hierarchy we characterized from ablation data has a biological analog in primate frontal cortex — categorical separation, channel-specific sorting, format-constrained recombination. The same computational problem (compose abstract representations while maintaining invariance) produces the same architectural solution across substrates.
